## Write → audit

1. Use `templates/family-brief.json` for stage0 and `templates/family-return-brief.json` for stages1–4. Each `stage-N/brief.json` records its objective, sources, prerequisites, deferred scope, lexical/form audit, question blueprint and curriculum claims with real page/question IDs. Candidates document genuine alternatives only; for straightforward returns candidates may be empty, with the chosen rationale in family_progression/extension instead. Return `extension` is practice/extend with rationale. Include `literacy_policy`: required script skill, actually taught support and reading/transliteration policy. Script literacy and incidental learner-language prose are not ranked target vocabulary. Family-plan/literacy metadata requires human review; it does not itself prove completeness.
2. Read pinned source_locale/locales. Source is es for English study, en otherwise;11learners exclude study and10translations exclude study/source. Author `<source>/stage-0..4/{lesson.md,quiz.md}` together and add each source stage's adaptation-notes.json as a string array (`[]` when there are no adaptations); final inventory requires notes for source and translations. Stage0 has1–5pages; returns have empty lesson.md for practice or1–2new extension pages. Practice cannot teach `this`; extension teaches new forms before its quiz. No copied base/placeholder recap. Each stage has25–50new questions, family125–250. Choose the number by the useful decisions and reinforcement it provides; neither25 nor50 is a quality target. Do not precommit every bank to the minimum before considering its coverage.
3. Choose the response operation deliberately: supported interpretation, selecting a supplied form, copying, cued form retrieval and independently constructing a message are different evidence. When producing a taught form is the goal and task-local reading/input support is real, include useful typed gaps rather than defaulting to recognition. When support is absent, keep an accessible response and plan concrete provision in the existing roadmap; neither word rank nor a brief's promise delivers a keyboard/reading skill. Do not require mastery of an entire script for a bounded response, force a blank percentage, or claim copying as unaided retrieval. Keep family capability stable while making decisions/context/form/misconception variation purposeful. Reinforcement need not be novel but must not be labeled new capability. A supplied negative word does not test choosing its placement; meaning among infinitives does not test finite/infinitive choice. Mix new and earlier words where useful without fixed ratios or every-word quotas. Use learner_decision/relationship_to_previous/evidence_plan to identify relevant conditions and any reduced assistance; remove a redundant cue when pedagogically useful, not automatically at every return.
4. Audit every target unit in examples/tables/audio/stems/options/feedback. known_rank must match canonical form and appropriate usage. A lemma does not license every sense/inflection/construction. Newly assessed forms need actual current or eligible prior teaching; current practice has none. Cite earlier own `stage:N` or actual external prior teaching, never later members merely because the family is written together. Unknown lexical items cannot be smuggled in as newly taught grammar; redesign instead.
5. Use distinct extension lesson IDs, family-unique page anchors and new bank/question IDs. Return QMD lesson remains base ID; question page is an eligible bare family anchor. Explanatory links can identify an eligible extension page. Do not concatenate Markdown or apply base five-page cap to the whole family; leave finalized external files immutable.
6. Start new banks from templates/quiz.md using project QMD0.2. Omit Sentence for a prompt-only choice when no target passage is needed; do not add a first-word cue to satisfy the frozen0.1 template. Keep meaningful target sentences for interpretation and gap choices; blank items require exactly one semantic gap. A present Sentence remains protected target content; learner directions go in Prompt. Mark target units explicitly even in explanations. Keep role labels/tips/translations in learner language, and do not accidentally freeze source prose as target. Options are protected by default. Only pure learner concept prose in a no-blank question may use reviewed `option_text_policies` learner entry. Mixed target/prose strings require redesign; plain options cannot protect partial spans.
7. Choice pools have4–10options, exactly one correct and3–9plausible distinct taught errors. Each distractor must be wrong under the exact prompt regardless of random draw. No positional/all-or-none references. Intended app draws three distractors and retains shuffled A–D for an attempt; no renderer implementation is claimed. For blanks substitute each accepted form, preserve accents/punctuation and deliberate case behavior, and eliminate unintended alternatives. Feedback resolves the decisive cue or tempting misunderstanding when useful, without a prose quota. Every item stands alone and maps to real teaching. The syntax template is not a task recipe: its six-option example is permitted only when all alternatives are taught and useful; four remains valid. Use varied information designs when the objective benefits—changed speakers, a conflicting fact, an intended action versus actual action, or a bounded phrase gap—not decorative stories or new unknown vocabulary.

## Self-check → independent diagnosis → enrichment → verification

Run `python3 -m lesson_factory.family_cli check --run RUN --locale SOURCE` for all five briefs/pairs, inspect warnings and self-solve every item. Check is not approval. Diagnose tool defects through authoring-tooling without weakening gates; coordinator assigns one owner.

Freeze all source stages/briefs and hand the same family to three source reviewers via `templates/assignment.md`, independent sessions and unique report paths. They do not edit source or see one another's initial verdict. Use `templates/family-review.json` with exactly five stage entries. Assessment question_checks covers every ID per stage with status/rationale and meaningful answer/alternatives/teaching_page evidence. Pedagogy/format record stage-specific lens evidence. After their independent diagnoses, pedagogy and assessment reviewers also identify useful enrichment opportunities in existing findings—or say no change is warranted. Coordinator chooses **keep, replace or add** by marginal learning value: keep sound reinforcement; replace an implausible foil, copied-result task or needless restriction; add an item/option only for worthwhile uncovered practice or encounter variety within the current limits. Clarifying learner-language context or improving feedback may add more value than another question. There is no proposal, edit, novelty, type or expansion quota. Record material dispositions, not a new approval form.

The coordinator owns source changes. A critic may propose candidate wording after its initial verdict, but becomes an author of that proposal: a different genuine assessment/pedagogy-capable reviewer must verify substantive authored changes and their dependencies. Use the existing roles; a new permanent editor role is unnecessary. Optional scoped editor/fresh-solver work is justified by a concrete gap, disputed interpretation or persistent shortcut—not by a bank merely having25 items. A genuinely key-hidden solver receives necessary learner-visible context without keys, feedback, semantic IDs or prior verdicts; someone who already saw the key cannot claim blinding. This supplements, not replaces, complete item review.

After edits, verify what the item now measures as well as whether its key is unique. A repair that says “use this exact answer, not that one” can destroy the original decision. Compare bank-level response/cue patterns with relevant earlier banks in learner-unlock order, retaining legitimate repeated retrieval. Coordinator preserves rejected reports and obtains fresh current-bound approvals under pack-review after source/brief edits and before translation; never silently add questions after localization or reuse pre-edit approval. Follow pack-review's progress-aware bounded repair passes and targeted integration correction, preserving used counts across resume. Use its non-review blocked handoff only for unavailable required inputs or unresolved substantive failure; do not stop a repairable heading or typo merely because two prior passes occurred, loop indefinitely or fabricate a report. Do not repeat voting until agreement; unresolved substantive issues block.

Draft-only ends only after all five valid source stages and three current full-family approvals. Otherwise end source team, load lesson-localization and dispatch only authorized full-family locale requests. Pack-review governs final publication. Report actual checks, not claims that lexical audits, metadata or parser success prove language quality.
