This per-option check usually suffices—enumerating all combinations is unnecessary unless an option depends on another. Reject positional/letter references, all/none-of-the-above, accidentally equivalent forms, regional alternatives, true statements that answer an ambiguous question, and linguistic/formatting clues that reveal the key. Extra options can dilute an essential contrast, so more stored combinations are not automatically better practice.

For each blank, substitute every accepted form into the complete sentence. Check word boundaries, scripts, accents, punctuation and deliberate case behavior; look for equally valid omitted alternatives. Fix ambiguity in context when accepting more answers would test a different skill. Do not add fuzzy matching or strip meaningful distinctions.
